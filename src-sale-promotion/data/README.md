# Sales Promotion Sample Data

Sample dataset for testing the sales promotion RAG pipeline.

## File

**sample_promotions_200.csv** - 200 realistic promotional campaigns

## Dataset

- **Rows**: 200
- **Columns**: 25
- **Date Range**: 2024

## Columns

promotion_id, promotion_name, brand, product_name, product_category, promotion_type,
discount_percentage, original_price, sale_price, start_date, end_date, duration_days,
season, campaign_type, region, target_age_group, impressions, clicks, ctr, conversions,
conversion_rate, revenue, campaign_cost, roi, status

## Categories

Electronics, Fashion, Beauty, Toys, Sports, Food, Health

- "Show high ROI electronics promotions"
- "Find BOGO deals under $100"
- "Best Holiday campaigns"
